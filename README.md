# 자동 손익 대시보드 (SCM 부트캠프 3차 과제)

Raw data 엑셀·CSV 파일을 올리면 **전사·본사·폴란드법인 손익계산서와 대시보드, 인사이트**가 자동으로 나오는 웹사이트입니다.
3차 과제에서 SUMIFS·차트·조건부 서식으로 며칠 걸려 만들던 결과물을, 바이브코딩으로 만든 사이트 하나가 몇 초 만에 만들어 냅니다.

- 사이트 주소: https://turtlelee-teacher.github.io/SCM_Dynamic_P-L_INCOME_STATEMENT/ (주소 끝에 `#sample` 을 붙이면 샘플이 바로 열립니다)
- 설치할 것이 없습니다. 저장소를 내려받아 `index.html` 을 더블클릭해도 동작합니다.
- 올린 파일은 **브라우저 안에서만** 처리되고 서버로 전송되지 않습니다.

## 쓰는 법

1. **파일 올리기**를 누르거나 화면에 파일을 끌어다 놓습니다. 먼저 보고 싶으면 **샘플로 체험**을 누릅니다.
2. 위쪽에서 **관점**(전사 · 법인)과 **기간**(시작 월 ~ 끝 월)을 고릅니다. 모든 숫자·차트·문장이 다시 계산됩니다.
3. 탭 5개를 넘겨 봅니다: 요약 · 손익계산서 · 수익성 · 판관비 · 인사이트.
4. **엑셀로 내보내기**를 누르면 SUMIFS 수식이 살아 있는 손익계산서 엑셀을 받습니다.

## 엑셀 과제와 무엇이 같고 무엇이 다른가

| 3차 과제에서 하던 일 | 이 사이트가 하는 일 |
|---|---|
| Raw data 정비 (빈 행·텍스트 숫자 정리) | 파일을 읽으면서 자동 정비하고, 버린 행은 **데이터 점검 리포트**에 사유별로 남깁니다 |
| SUMIFS 로 전사·본사·폴란드법인 3벌 전개 | 계산 엔진이 한 번 집계하고 관점 버튼으로 바꿔 봅니다. 법인이 늘어도 버튼만 늘어납니다 |
| 전사 = 본사 + 폴란드법인 검산 | 손익계산서 탭 아래에 **검산 결과**(금액 칸 전부 일치 여부)를 매번 보여줍니다 |
| 이익률 합계 칸 (월 이익률을 더하는 실수) | 합계 열 이익률은 항상 **합계 ÷ 합계**로 계산합니다 |
| 조건부 서식 | 음수는 빨강, 합계보다 5%p 이상 낮은 이익률은 블루, 적자월은 머리글에 빨간 점을 찍습니다 |
| 분기 차트 (누계와 분기 실적 혼용) | 분기 실적 기준으로만 그리고, 차트 아래에 기준을 적어 둡니다 |
| 폭포차트 | 매출액 → 매출원가 → 매출이익 → 판관비 → 영업이익 → 영외수지 → 세전이익 |
| 인사이트 도출 | 규칙 9개가 숫자에서 문장을 만들고, 1위 문장을 헤드메시지로 올립니다 |

## 입력 파일 형식

과제 원본 `손익계산서_Raw data` 시트와 같은 모양이면 그대로 올리면 됩니다.

| 열 | 예시 | 필수 |
|---|---|---|
| 회사명 | 본사, 폴란드법인 | ✅ |
| 월 또는 거래일시 | `1월` · `1` · `20220101` · `2022-01-01` | ✅ (둘 중 하나) |
| 대분류 코드 | 매출액 · 매출원가 · 판매관리비 · 영외수지 | ✅ |
| 중분류 코드 | 재료비 · 판촉비 · 영업외수익 … | ✅ |
| 금액 | `15839296` · `" 15,839,296 "` | ✅ |
| 손익계산 ID · 년도 · 일 · 전표번호 · 소분류 코드 | | 선택 |

- 열 순서, 열 이름 앞뒤 공백, 표 위의 제목 행은 상관없습니다. 앞 15행 안에서 헤더를 찾습니다.
- 여러 시트가 있는 통합문서(과제 제출본 전체)를 올려도 Raw data 시트를 스스로 찾습니다.
- 한글 엑셀에서 저장한 CSV(CP949)와 UTF-8 CSV 를 모두 읽습니다.
- 양식에 없는 중분류(예: 판매관리비 아래 `광고선전비`)는 해당 구분의 하위 행으로 붙이고, 어디에도 속하지 않는 분류는 빼고 리포트에 적습니다.

## 화면 구성

| 탭 | 내용 |
|---|---|
| 요약 | KPI 4개(매출액·영업이익·영업이익률·판관비율), 월별 매출액과 영업이익률, 손익 폭포차트, 먼저 볼 인사이트 3개 |
| 손익계산서 | 과제 양식 20행 × (합계 + 월/분기), 단위 원·천원·백만원, 조건부 강조, 전사 검산 |
| 수익성 | 법인별 이익률 3종 비교, 매출 100원의 쓰임새, 분기별 영업이익·이익률, 원가 항목 비율 추이 |
| 판관비 | 판관비 구성, 월별 누적 추이, 판관비율 추이, 항목별 증감표, 법인별 항목 비율 비교 |
| 인사이트 | 규칙 기반 인사이트 카드(근거 숫자 포함)와 종합 시사점 |

## 인사이트 규칙 9개

| 규칙 | 조건 |
|---|---|
| 이익 기여도 | 영업이익 비중이 매출 비중과 15%p 이상 차이 나거나 60%를 넘는 법인 |
| 이익률 격차 | 법인 간 영업이익률 차이 10%p 이상 (법인 관점에서는 전사 평균과 5%p 이상) |
| 원가 구조 차이 | 매출 대비 비율이 법인 간에 5%p 이상 벌어진 비용 항목 |
| 성장의 질 | 매출은 늘었는데 영업이익률이 3%p 이상 떨어짐, 또는 그 반대 |
| 비용으로 지킨 이익 | 매출이 줄 때 50% 이상 줄어든 판관비 항목 |
| 빠르게 오르는 비용 | 매출 대비 비율이 5%p 이상 오른 비용 항목 |
| 적자월 | 영업이익이 음수인 달과, 앞뒤 달보다 그 달에 튄 비용 항목 |
| 영외수지 | 영외수지가 영업이익을 깎거나 보태는 규모 |
| 판관비율 추세 | 분기마다 한 방향으로 3%p 이상 움직인 판관비율 |

비교 구간은 선택 기간이 6개월 이상이면 앞 3개월 대 뒤 3개월(1분기 대 4분기), 그보다 짧으면 첫 달 대 마지막 달입니다.

## 샘플 데이터

`sample/` 의 파일은 **가상 데이터**입니다. 과제 원본과 열·행 배분(회사당 월 50행, 총 1,200행)만 같고 금액은 새로 만들었습니다.
과제 원본은 다음 기수도 쓰므로 저장소에 넣지 않았습니다. 시연할 때는 원본 파일을 직접 올리면 됩니다.

- `sample_rawdata.xlsx`: 맨 위에 제목 행이 있어 헤더 자동 탐지를 보여줍니다
- `sample_rawdata.csv`: UTF-8 CSV
- 다시 만들기: `node scripts/make-sample.js` (시드 고정이라 항상 같은 결과)

## 바이브코딩 제작 과정

이 사이트는 Claude Code 와 대화하며 만들었습니다. 사람은 목적과 판단을 정하고, 코드와 검증은 AI 가 맡았습니다.

1. **요구 정리**: "3차 과제 Raw data 를 넣으면 손익계산서와 대시보드가 나오는 사이트"를 말하고, 노션의 과제 안내와 멘티 피드백을 읽혀 양식·검증 기준을 확정했습니다.
2. **선택 4가지**: 정적 웹(설치 없음) · 규칙 기반 인사이트(API 키 없음) · 가상 샘플(원본 비공개) · 토글 + 탭 5개 화면을 골랐습니다.
3. **계산 엔진부터**: 화면보다 먼저 손익 계산을 만들고, 과제 원본을 넣어 멘티 엑셀의 SUMIFS 결과와 **원 단위까지** 대조했습니다(원본과 정답 숫자는 저장소에 넣지 않았습니다).
4. **화면과 검수**: 브라우저를 자동으로 띄워 5개 탭 × 3개 관점 × 데스크톱·모바일 화면을 찍어 보고 잘린 라벨·겹침을 고쳤습니다.
5. **엑셀로 되돌리기**: 내보낸 엑셀의 SUMIFS 수식 780칸을 수식 계산기로 다시 계산해 화면 값과 전부 일치하는지 확인했습니다.

## 자동 병합과 배포

- 같은 저장소의 `claude/` 브랜치 PR 은 **자동 병합**됩니다(`.github/workflows/auto-merge.yml`). 단위 테스트와 샘플 재생성 검사를 통과하면 병합하고 Pages 배포를 띄웁니다.
- 병합을 막고 싶은 PR 에는 `hold` 라벨을 붙입니다.
- 워크플로 파일을 고치는 PR 은 워크플로 토큰 권한 밖이라, 검사 통과 뒤 PR 을 만든 세션이 병합합니다.
- 배포는 `.github/workflows/pages.yml` 이 맡습니다. 저장소 Settings → Pages → Source 가 **GitHub Actions** 여야 합니다(처음 한 번).

## 개발

```bash
npm test          # 단위 테스트 (node 18 이상, 설치 불필요)
npm run sample    # 가상 샘플 다시 만들기
npm start         # http://localhost:8080 에서 보기
```

외부 라이브러리는 `vendor/` 에 넣어 두어 인터넷이 없는 교실에서도 동작합니다. 글꼴(Pretendard)만 CDN 에서 받고, 받지 못하면 시스템 글꼴로 바뀝니다.
